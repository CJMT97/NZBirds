# NZBirds Website 🐦🇳🇿

The **NZBirds Website** is a simple, visual guide to bird species found throughout New Zealand. It displays images alongside key information to help users learn about the country’s unique and diverse native birds.

This project is designed to be easy to explore and is suitable for anyone interested in New Zealand wildlife, from casual bird enthusiasts to students.

🔗 **Live site:** https://cjmt97.github.io/NZBirds/

## Features
- Image gallery of New Zealand bird species  
- Basic information for each bird  
- Clean and easy-to-navigate layout  

## Purpose
The goal of this project is to provide an accessible way to discover and appreciate the birds of Aotearoa New Zealand.
